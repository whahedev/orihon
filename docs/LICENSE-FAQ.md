# License FAQ

Orihon the map engine is licensed under the [Apache License 2.0](../LICENSE).

## Can I use Orihon in a commercial product?

Yes. Apache 2.0 allows use, modification, and distribution, including in proprietary and commercial products, without a separate paid engine license.

## Do I need to talk to sales before `npm install`?

No. Install from npm and ship.

## Is this OSI-approved open source?

Yes. Apache License 2.0 is an OSI-approved open-source license.

## What about Orihon Studio?

The engine is the library. Orihon Studio is a visual scene editor for building maps on top of that engine (`npm run demo:studio`).

## What happened to PolyForm Noncommercial and the paid commercial agreement?

Current Orihon releases are Apache 2.0. Those earlier terms do not apply to this license. See [LICENSE](../LICENSE) and [LICENSE-NOTICE.md](../LICENSE-NOTICE.md).
