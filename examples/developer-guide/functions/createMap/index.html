Функции/Карта и камера

orihon/core

createMap()

Создаёт карту Orihon внутри указанного HTML-контейнера и настраивает начальный центр, масштаб и элементы управления.

Исходник · L1008

Для чего нужна

Создаёт карту Orihon внутри указанного HTML-контейнера и настраивает начальный центр, масштаб и элементы управления.

Функция относится к разделу «Карта и камера». Создание карты, управление камерой и группировка слоёв.

Импорт

ts
import { createMap } from "orihon/core";

Сигнатура и результат

ts
function createMap(container: string | HTMLElement, options?: MapOptions): Orihon

Возвращает: Orihon — значение типа Orihon, описанное в сигнатуре выше

Параметры

ПараметрТипОбязателенПо умолчаниюОписание
containerstring | HTMLElementда—HTML-элемент карты либо его строковый id. Контейнер должен иметь ненулевые ширину и высоту.
optionsMapOptions | undefinedнет—Необязательные настройки поведения. Все поддерживаемые поля, их единицы и назначение перечислены в таблице ниже.

Состав options

Объект MapOptions | undefined поддерживает следующие поля:

ПолеТипОбязательноеНазначение
centerLatLngLike | undefinedнетНачальный центр карты в географических координатах [широта, долгота].
zoomnumber | undefinedнетМасштаб карты, используемый при выборе плотности сетки; географический kernel остаётся стабильным.
minZoomnumber | undefinedнетМинимальный zoom, на котором объект доступен или видим.
maxZoomnumber | undefinedнетМаксимальный zoom, на котором объект доступен или видим.
zoomSnapnumber | undefinedнетШаг округления zoom; 1 разрешает только целые уровни, 0 отключает округление.
wheelZoomStepnumber | undefinedнетИзменение zoom за один нормализованный шаг колеса или trackpad.
maxBoundsLatLngBoundsLike | null | undefinedнетГеографическая область, за пределы которой пользователю нельзя переместить центр карты; null снимает ограничение.
maxBoundsViscositynumber | undefinedнетСопротивление выходу за maxBounds от 0 до 1; 1 полностью удерживает карту внутри области.
inertiaboolean | undefinedнетВключает продолжение движения карты после отпускания указателя.
inertiaDecelerationnumber | undefinedнетЗамедление инерционного перемещения в CSS-пикселях за секунду в квадрате.
inertiaMaxSpeednumber | undefinedнетМаксимальная скорость инерционного перемещения в CSS-пикселях в секунду.
zoomAnimationDurationnumber | undefinedнетПродолжительность программной анимации zoom в миллисекундах.
controlsboolean | undefinedнетАвтоматически добавляет стандартные элементы управления карты.
localeLocaleInput | undefinedнетЯзык интерфейса или пользовательский словарь переводов.
ariaLabelstring | undefinedнетДоступное имя контейнера или элемента для screen reader.
keyboardboolean | undefinedнетВключает управление картой с клавиатуры.
keyboardPanDeltanumber | undefinedнетСмещение карты одним нажатием стрелки в CSS-пикселях.
behaviorsPartial<Record<MapBehaviorName, boolean>> | undefinedнетТочечно включает или отключает drag, wheel, double-click и другие способы взаимодействия.
crsCRSInput | undefinedнетСистема координат карты; по умолчанию используется Web Mercator.

Пример

ts
import { createMap, tileLayer } from "orihon/core";
import "orihon/orihon.css";
const map = createMap("map", {
center: [55.751244, 37.618423],
zoom: 10,
locale: "ru"
});
tileLayer("https://tile.openstreetmap.org/{z}/{x}/{y}.png").addTo(map);

Интерактивный пример

Измените код слева и запустите его. Карта справа создаётся заново перед каждым запуском, поэтому эксперименты не накапливают слои.
