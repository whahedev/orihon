Функции/Производительность и инфраструктура

orihon

geometryWorkerPool()

Устаревший alias createGeometryWorkerPool; создаёт отдельный пул, принадлежащий вызывающему.

Исходник · L608

Для чего нужна

Устаревший alias createGeometryWorkerPool; создаёт отдельный пул, принадлежащий вызывающему.

Функция относится к разделу «Производительность и инфраструктура». Workers, offline-кэш, адаптеры, инспекция и служебные структуры.

Импорт

ts
import { geometryWorkerPool } from "orihon";

Сигнатура и результат

ts
function geometryWorkerPool(options: GeometryWorkerOptions = {}): GeometryWorkerPool

Возвращает: GeometryWorkerPool — значение типа GeometryWorkerPool, описанное в сигнатуре выше

Параметры

ПараметрТипОбязателенПо умолчаниюОписание
optionsGeometryWorkerOptionsнет{}Необязательные настройки поведения. Все поддерживаемые поля, их единицы и назначение перечислены в таблице ниже.

Состав options

Объект GeometryWorkerOptions поддерживает следующие поля:

ПолеТипОбязательноеНазначение
useWorkerboolean | undefinedнетВключает или отключает поведение «use worker».

Пример

ts
import { geometryWorkerPool } from "orihon";

const result = geometryWorkerPool();

Интерактивный пример

Измените код слева и запустите его. Карта справа создаётся заново перед каждым запуском, поэтому эксперименты не накапливают слои.
