Функции/Маркеры и оверлеи

orihon/standard

marker()

Создаёт интерактивный DOM-маркер в географической точке с popup, tooltip и обработчиками событий.

Исходник · L476

Для чего нужна

Создаёт интерактивный DOM-маркер в географической точке с popup, tooltip и обработчиками событий.

Выберите один режим: встроенная фигура (shape/color/size), content или icon. Смешанные режимы и устаревший html отклоняются. Пустой content остаётся пустым. setContent(), setIcon() и setAppearance() явно переключают режим; anchor для иконки задаётся через iconAnchor.

Импорт

ts
import { marker } from "orihon/standard";

Сигнатура и результат

ts
function marker(position: LatLngLike, options?: MarkerOptions): Marker

Возвращает: Marker — экземпляр API, который можно настроить и добавить на карту

Параметры

ПараметрТипОбязателенПо умолчаниюОписание
positionLatLngLikeда—Именованная координата { lat, lng } или LatLng. GeoJSON-пары преобразуйте через fromGeoJSONPosition().

Пример

Тот же код, что можно скопировать к себе, — и он же выполняется на карте справа. Здесь отбрасываются только строки import: всё остальное, включая создание карты, выполняется как есть, а вывод console.log() попадает в панель результата. Контейнер карты очищается перед каждым запуском, поэтому эксперименты не накапливают слои.
