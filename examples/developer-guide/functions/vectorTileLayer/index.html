Функции/Растровые тайлы

orihon

vectorTileLayer()

Запрашивает векторные тайлы через provider и отображает их геометрию по правилам paint.

Исходник · L195

Для чего нужна

Provider остается внешним, Orihon отвечает за lifecycle и отображение.

Импорт

ts
import { vectorTileLayer } from "orihon";

Сигнатура и результат

ts
function vectorTileLayer(options: VectorTileLayerOptions): VectorTileLayer

Возвращает: VectorTileLayer — экземпляр API, который можно настроить и добавить на карту

Пример

Тот же код, что можно скопировать к себе, — и он же выполняется на карте справа. Здесь отбрасываются только строки import: всё остальное, включая создание карты, выполняется как есть, а вывод console.log() попадает в панель результата. Контейнер карты очищается перед каждым запуском, поэтому эксперименты не накапливают слои.
