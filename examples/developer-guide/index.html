Руководство разработчика

ORIHON — Offers Responsive Interactions, Handles Overlays Natively.

Одна публичная функция — одна отдельная страница. Каталог покрывает корневой вход orihon и опциональные orihon/source, orihon/draw, orihon/controls, orihon/geo, orihon/popup-content, orihon/pmtiles, orihon/mlt; у каждой страницы указан вход, из которого её импортируют. Список и сигнатуры берутся из текущих TypeScript-входов, поэтому удалённая функция исчезает, а новая появляется сама. orihon/easy отдельных страниц не имеет: его API — это createMap из корневого входа и методы возвращённой карты, см. docs/EASY.md. Описания перенесены из Confluence и обновлены под действующую архитектуру.

105 функций11 разделовCore · Standard · Advanced
Package tier ≠ сложность API. Core, Standard и Advanced отвечают за состав и gzip budget. Easy, Layer API и Rendering API отвечают за уровень управления. orihon/easy работает поверх Standard и остаётся map-centric / object-first: map.addMarker({ position, appearance }), map.addPolyline({ points, style }), map.addPolygon({ rings, style }), map.addGeoJSON({ data }), map.addTileLayer({ url }). Декларативный map.add({ type }) и позиционные Easy-формы удалены. Возвращаемые значения — обычные объекты Orihon. Standard по-прежнему layer-centric: marker(…).addTo(map).
Heat API обновлён. Старые webglHeatLayer, heatIsolineLayer и buildHeatIsolines исключены. Используйте heatLayer(), buildHeat() и heatSupport().
