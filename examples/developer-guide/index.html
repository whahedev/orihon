Руководство разработчика

Каждая публичная функция — своя страница: сигнатура, параметры и пример, который выполняется здесь же на карте. Ниже — весь каталог: команда, вход, из которого её импортируют, и что она делает. Список берётся из входов src/, поэтому удалённая функция исчезает, а новая появляется сама.

С чего начать

Из пустой папки одна команда создаёт проект, в котором карта уже рисуется — со стилями, высотой контейнера и attribution:

sh
npm create orihon-app my-map
cd my-map
npm install
npm run dev

В существующем приложении — установка и первая карта:

sh
npm install orihon
js
import { createMap } from "orihon/easy";
import "orihon/orihon.css";

const map = createMap("map", {
  center: { lat: 52.52, lng: 13.405 },
  zoom: 12,
  basemap: {
    url: "https://tile.openstreetmap.org/{z}/{x}/{y}.png",
    attribution: "© OpenStreetMap contributors"
  }
});

Контейнеру нужна собственная высота: у <div> её нет, и карта отрисуется в ничто. Orihon сообщает об этом в консоль — см. Troubleshooting.

Уровень пакета и сложность API — разные вещи. orihon/core, orihon/standard и orihon отвечают за состав и gzip-бюджет, а Easy, Layer API и Rendering API — за уровень управления; orihon/easy работает поверх Standard и остаётся map-centric (map.addMarker({ position })), а Layer API — layer-centric (marker(position).addTo(map)). Полный контракт Easy — в docs/EASY.md, весь публичный список команд — в docs/API.md.
