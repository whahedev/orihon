Руководство разработчика

ORIHON — Offers Responsive Interactions, Handles Overlays Natively.

Одна публичная функция — одна отдельная страница. Сигнатуры и список функций берутся из текущего TypeScript API; описания перенесены из Confluence и обновлены для действующей архитектуры.

72 функций11 разделовCore · Standard · Advanced
Package tier ≠ сложность API. Core, Standard и Advanced отвечают за состав и gzip budget. Easy, Layer API и Rendering API отвечают за уровень управления. orihon/easy работает поверх Standard: единый декларативный map.add({ type, ... }) подходит для React/Vue/Svelte, а автодополнение map.add… показывает специализированные методы для маркеров, линий, полигонов, GeoJSON и тайлов. Возвращаемые значения остаются обычными объектами Orihon. Для готового слоя доступны оба равнозначных стиля: map.add(layer) и layer.addTo(map).
Heat API обновлён. Старые webglHeatLayer, heatIsolineLayer и buildHeatIsolines исключены. Используйте heatLayer(), buildHeat() и heatSupport().

Вычисления без отрисовки

21

Чистые вычисления и преобразования данных: геодезия, проекции, bounds, декодирование, heat field и packed-геометрия. Эти функции сами ничего не добавляют на карту.

bounds()

Создаёт расширяемую географическую область по двум углам, массиву координат или существующему объекту границ.

orihon/core → buildHeat()

Строит scalar field и, при необходимости, изолинии без создания слоя карты.

orihon → clampLat()

Ограничивает широту диапазоном, который корректно отображается проекцией Web Mercator.

orihon/core → createWMTSFromCapabilities()

Разбирает XML WMTS GetCapabilities в конфигурацию, пригодную для wmtsTileLayer.

orihon/standard → decodeMVT()

Декодирует бинарный MVT-тайл в набор геометрий и свойств, доступных JavaScript-коду.

orihon → destination()

Находит координату, расположенную на заданном расстоянии и азимуте от исходной точки по поверхности Земли.

orihon/core → distance()

Вычисляет кратчайшее геодезическое расстояние между двумя координатами в метрах.

orihon/core → geodesicInterpolate()

Добавляет промежуточные точки вдоль дуги большого круга, чтобы длинная линия корректно следовала кривизне Земли.

orihon/core → latLng()

Нормализует поддерживаемый формат координаты в объект LatLng с широтой и долготой.

orihon/core → lngLat()

Создаёт LatLng из longitude-first координат MapLibre, GeoJSON и совместимых API.

orihon/core → markerShapeMetrics()

Возвращает размеры и точки привязки встроенной формы маркера для собственного layout или renderer.

orihon/standard → metersToPixels()

Переводит реальное расстояние в экранные пиксели для заданной широты и масштаба Web Mercator.

orihon/core → point()

Создаёт двумерную точку в экранных или мировых пиксельных координатах; это не широта и долгота.

orihon/core → pointBounds()

Создаёт прямоугольную область в пиксельной системе координат по двум точкам или набору точек.

orihon/core → preparePointBatch()

Синхронно упаковывает точки в типизированные массивы, пригодные для массовой GPU-отрисовки.

orihon → preparePointBatchAsync()

Кооперативно подготавливает большой iterable или async iterable точек без длительной блокировки main thread.

orihon → project()

Переводит географическую координату в мировые пиксели Web Mercator на указанном zoom.

orihon/core → scale()

Возвращает ширину мира Web Mercator в пикселях на заданном уровне масштаба.

orihon/core → unproject()

Преобразует мировую пиксельную точку Web Mercator обратно в широту и долготу.

orihon/core → wrapLng()

Переносит долготу в стандартный диапазон от −180° включительно до 180°.

orihon/core → zoomForBounds()

Подбирает максимальный zoom, при котором заданная географическая область целиком помещается в viewport.
