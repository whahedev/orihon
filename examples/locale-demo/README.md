# Orihon — locale switcher demo

Separate test page: switch UI language via the `locale` option.

Changing language **recreates** the map with the new `locale` (center and zoom are preserved). Available: `en`, `ru`, `ar`, `tr`, `zh`, `de`, `fr`, `da`, `hi`.

## Run

```bash
npm run demo:locale
```

Open http://localhost:4173 and pick a language in the select.
