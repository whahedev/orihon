# Навигация по OSM

Отдельный блок построения маршрута:

- **Источник дорог:** OpenStreetMap (`highway=*`) через публичный [OSRM](https://project-osrm.org/)
- **Профили:** авто (время OSRM) / вело ~16 км/ч / пешком ~5 км/ч
- **Варианты:** альтернативные пути OSM + разные скорости; сортировка по времени
- Выбор варианта в панели или кликом по линии на карте

Публичный demo-сервер OSRM отдаёт только автомобильный граф; вело и пешком используют те же геометрии дорог с оценкой времени.

## Run

```bash
npm run demo:navigation
```

Откройте http://127.0.0.1:8791/examples/navigation/

Или из корня репозитория:

```bash
npx --yes serve . -l 8791
```

## Notes

- Публичный `router.project-osrm.org` — только для демо.
- В проде подключайте свой OSRM / Valhalla / GraphHopper к Orihon `routingLayer`.
