# РЖД 121В/122В — исправленный прототип

## Что исправлено

- исправлен `ReferenceError: dwellMinutes is not defined`;
- расписание в списке остановок теперь отсчитывается от правильного отправления 15:57 МСК;
- добавлены прибытие, отправление и длительность стоянки для каждой промежуточной остановки;

- добавлен локальный HTTP-сервер, чтобы не запускать Orihon через `file://`.

## Запуск на Windows

По умолчанию в zip указан порт `8787`, но рядом уже может работать Air+Sea Radar.
В этом репозитории трекер РЖД слушает **8788**.

Из корня Orihon:

```bash
npm run demo:rzd
```

Или вручную:

```powershell
$env:PORT=8788; node server.mjs
```

Откройте:

```text
http://127.0.0.1:8788
```

## Ручной запуск (порт по умолчанию)

Нужен Node.js 18+:

```bash
node server.mjs
```

Затем откройте:

```text
http://127.0.0.1:8787
```

Не рекомендуется открывать `index.html` двойным кликом через `file://`.
