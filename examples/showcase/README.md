# Orihon scale showcase

Full-bleed product demo: **Core → Standard → Advanced**, then stress scenarios (100k vehicles, 250k IoT, live fleet, 50k clusters, aircraft, incident heat).

Self-contained `index.html` — open the file directly (Orihon loads from jsDelivr). No build or local server required.

Live: https://whahedev.github.io/orihon/showcase/
