# Orihon — WebGL points demo

Marketing / stress demo for `WebGLPointLayer` + `performanceInspector`.

Switch between **100k**, **500k** and **1M** points and watch:

- FPS
- frame time
- JS heap memory (Chromium)
- source / visible / rendered point counts

## Run

From the package root (needs a prior `npm run build`):

```bash
npm run demo:webgl
```

Open http://localhost:4175/examples/webgl-points-demo/
