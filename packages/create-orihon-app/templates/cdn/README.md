# Orihon map (CDN)

One HTML file, no bundler. Open it through a tiny static server (browsers block ES modules from `file://`).

```sh
npx --yes serve .
```

Then open the printed URL. Edit `index.html`: change the centre, delete overlay blocks you do not need.
